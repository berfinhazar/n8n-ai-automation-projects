# n8n AI Automation Projects


Bu depo, n8n ile yapay zekâ otomasyonu ve LLM destekli iş akışları üzerine yaptığım kurs çalışmaları ve uygulamalı projeleri içerir.

### Projeler

- E-posta otomasyonu ve yapay zekâ ile e-posta içeriği oluşturma
- Form değerlendirme ve metin analizi
- Pinecone ile vektör veritabanı ve RAG uygulamaları
- Tesla finansal verileri üzerinde RAG ve AI Agent çalışması
- Google Drive üzerinden dosya yükleme ve işleme
- Telegram üzerinden e-posta ve takvim işlemleri
- Telegram alt iş akışları

### Kullanım

1. İlgilendiğiniz JSON iş akışı dosyasını indirin.
2. n8n içerisinde **Import from File** seçeneğiyle içe aktarın.
3. Gerekli servisler için kendi kimlik bilgilerinizi (credentials) yapılandırın.
4. Çalıştırmadan önce node ayarlarını ve bağlantıları kontrol edin.


## English

This repository contains hands-on projects and coursework focused on AI automation and LLM-powered workflows using n8n.

### Topics

- Email automation and AI-generated email content
- Form evaluation and text analysis
- Vector databases and RAG with Pinecone
- RAG and AI Agent workflows using Tesla financial data
- File ingestion and processing with Google Drive
- Email and calendar automation through Telegram
- Telegram sub-workflows

### Setup and Usage

1. Download the desired workflow JSON file.
2. Import it into n8n using **Import from File**.
3. Configure your own credentials for the required services.
4. Review node settings and connections before execution.
